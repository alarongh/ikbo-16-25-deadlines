# Дедлайны ИКБО-16-25

Статический трекер практик, тестов и других работ на осенний семестр 2026 года. HTML, CSS и JavaScript без сборки и внешних зависимостей.

Сайт: https://alarongh.github.io/ikbo-16-25-deadlines/

## Запуск

Откройте `index.html` либо запустите `python -m http.server 8000` и перейдите на `http://localhost:8000`.

## Изменение данных

Предметы, задания, расписание и даты находятся в `data.js`. Сохраняйте `id` при переименовании задания: отметки браузера привязаны к этому идентификатору.

Виды сроков:

- `weeks`: дата занятия в последней учебной неделе диапазона; завершение указанной пары.
- `date`: конкретная дата, включительно до конца дня.
- `window`: включительный период календарных дат; в выборе ближайшего срока участвует последний день.
- `weekWindow`: включительное окно учебных недель, до воскресенья последней недели.
- `semester`: до конца семестра, без выдуманной даты. В автоматическую сортировку сроков не входит.

Учебная неделя 1 начинается 01.09.2026; календарная точка отсчёта — понедельник 31.08.2026. Неделя 3: 14–20.09.2026. Все даты и времена рассчитываются в часовом поясе браузера, без разбора ISO-дат как UTC.

В интерфейсе номера учебных недель заменены календарными датами: показываются диапазон периода и отдельная дата последней пары. Исходные номера недель сохранены в `data.js` для расчёта и дальнейшего изменения данных.

Пары для сроков `weeks`: архитектура — четверг, 3-я; администрирование — понедельник, 1-я; Java — вторник, 2-я. Для остальных предметов расписание также записано в данных, но окна и точные даты не заменяются датами пар. Дата окончания семестра не установлена. Время окончания пары используется как расчётная граница; точное время приёма работы внутри пары неизвестно.

## Поведение

Ближайший срок и следующий за ним — две различные будущие даты среди несданных заданий. Все задания с одинаковой датой показываются вместе. После окончания пары или календарного дня несданное задание остаётся в списке с пометкой «Срок прошёл», а ближайший срок выбирается из предстоящих. Завершённые работы не участвуют в выборе.

Прогресс сохраняется в `localStorage`, ключ `ikbo-16-25.deadlines.completed.v1`. Отметки отдельные для каждого браузера и адреса сайта. Вкладки одного браузера синхронизируются. Сервер, аккаунты и передача отметок по сети отсутствуют.

Меню «Открыть предмет» закреплено сверху при прокрутке. Оно открывает отдельное окно со всеми работами выбранного предмета; там подсвечиваются ближайший и следующий сроки именно этого предмета. Отметки общие с основным списком. Предмет также открывается по его названию или по заданию в верхней карточке. Окно закрывается кнопкой «Закрыть» или Escape.

## Сверка с исходными данными

| Предмет | Задания |
| --- | --- |
| Архитектура | 4 блока с диапазонами 3–6, 7–9, 9–12, 13–16 недель |
| Конфигурационное управление | Без работ и сроков |
| Администрирование | 4 практики, тест, курсовая |
| Java | 7 практик и аудиторное контрольное тестирование |
| ИИ и большие данные | 4 блока и 2 контрольных теста |
| Структуры и алгоритмы | 4 практики с исходными номерами 1 (5) — 4 (8) |
| Фронтенд | 4 проектные работы и 5 тестов; даты по четвергам |

Всего 37 заданий. При сверке с предоставленными пользователем скриншотами исправлена пара практики по администрированию: понедельник, 1-я пара (до 10:30), вместо ошибочно указанной 3-й. Тест по администрированию на 15–16-й неделях помечен как ориентир: дата открытия и доступный срок пока неизвестны. Текущая аттестация СиАОД от 24.08.2026 на скриншоте находится до начала указанного семестра и не добавлена в список практик. Пересечение 9-й недели между блоками архитектуры сохранено. Сроки конца семестра не заменены выдуманной датой, календарные окна СиАОД не заменены датами пар.
