# Дедлайны ИКБО-16-25

Статический трекер практик, тестов и других работ на осенний семестр 2026 года. HTML, CSS и JavaScript без сборки и внешних зависимостей.

Сайт: https://alarongh.github.io/ikbo-16-25-deadlines/

## Запуск

Откройте `index.html` либо запустите `python -m http.server 8000` и перейдите на `http://localhost:8000`.

## Изменение данных

Предметы, задания, расписание и даты находятся в `data.js`. Сохраняйте `id` при переименовании задания: отметки браузера привязаны к этому идентификатору.

Виды сроков:

- `weeks`: дата занятия в последней учебной неделе диапазона; завершение указанной пары.
- `date`: конкретная дата, включительно до конца дня.
- `window`: включительный период календарных дат; в выборе ближайшего срока участвует последний день.
- `weekWindow`: включительное окно учебных недель, до воскресенья последней недели.
- `semester`: до конца семестра, без выдуманной даты. В автоматическую сортировку сроков не входит.

Учебная неделя 1 начинается 01.09.2026; календарная точка отсчёта — понедельник 31.08.2026. Неделя 3: 14–20.09.2026. Все даты и времена рассчитываются в часовом поясе браузера, без разбора ISO-дат как UTC.

Пары для сроков `weeks`: архитектура — четверг, 3-я; администрирование — понедельник, 3-я; Java — вторник, 2-я. Для остальных предметов расписание также записано в данных, но окна и точные даты не заменяются датами пар. Дата окончания семестра не установлена.

## Поведение

Ближайший срок и следующий за ним — две различные будущие даты среди несданных заданий. Все задания с одинаковой датой показываются вместе. После окончания пары или календарного дня несданное задание остаётся в списке с пометкой «Срок прошёл», а ближайший срок выбирается из предстоящих. Завершённые работы не участвуют в выборе.

Прогресс сохраняется в `localStorage`, ключ `ikbo-16-25.deadlines.completed.v1`. Отметки отдельные для каждого браузера и адреса сайта. Вкладки одного браузера синхронизируются. Сервер, аккаунты и передача отметок по сети отсутствуют.

## GitHub Pages

Публикация из ветки `main`, каталога `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Все ссылки на ресурсы относительные, поэтому сайт работает в подкаталоге репозитория.
